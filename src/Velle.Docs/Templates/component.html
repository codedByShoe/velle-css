Third-party library

This component is an adapter for {{ escape_html library.Package }} ({{ escape_html library.License }} license). velle-css does not ship or bundle it, and it is not part of dist/velle.js. Install version {{ escape_html library.Version }} (the version the adapter is tested against) in one of these ways:

With a bundler

npm install{{ for package in library.Packages }} {{ escape_html package }}{{ end }}
{{ if library.Stylesheet != "" }}

Then import {{ escape_html library.Package }}/{{ escape_html library.Stylesheet }} before {{ escape_html page.Component.Metadata.Name }}.css, so velle's theme overrides the library's defaults.

{{ end }}

Without a build step

Map the package name to a CDN build in an import map, placed before any module script:

{{ escape_html page.Component.ImportMapEntry }}{{ if library.Stylesheet != "" }}
<link rel="stylesheet" href="{{ escape_html library.StylesheetUrl }}"> <!-- before {{ escape_html page.Component.Metadata.Name }}.css -->{{ end }}

When you use the dist/velle.js bundle, load the adapter from dist/adapters/: those copies share the bundle's runtime.
