Velle

A unified Blazor Static SSR component library built on plain CSS design tokens and Alpine.js CSP — write Razor components across your entire UI with zero SignalR circuit or WebAssembly payload.

Built for Static SSR

One Razor API

Use consistent <Velle*> Razor components for buttons, alerts, cards, inputs, switches, tabs, dialogs, and datepickers — all sharing Class, AdditionalAttributes, and strongly-typed enums.

EditForm & Enhanced Sync

Form controls integrate with cascading EditContext and For expressions for automatic validation styling, while Alpine.js CSP re-syncs interactive state on every Blazor enhancedload.

Plain CSS tokens & utilities

One <VelleStyles /> tag ships light/dark semantic tokens, component CSS, and logical layout utilities with automatic .NET 10 asset fingerprinting.

Quick start

Requires the .NET 10 SDK and a Blazor Web App using Static SSR with app.MapStaticAssets() and blazor.web.js.

1. Install Velle.Blazor

Install Velle.Blazor ({{ escape_html page.Site.BlazorVersion }}) from NuGet.org:

sh 
dotnet add package Velle.Blazor --version {{ escape_html page.Site.BlazorVersion }}

2. Import the namespace

Add Velle.Blazor to Components/_Imports.razor:

razor 
@using Velle.Blazor

3. Add <VelleStyles /> in Components/App.razor

<VelleStyles /> renders fingerprinted stylesheet links using ASP.NET Core's @Assets[...] collection. JavaScript loads automatically through Blazor's JS initializer — no manual script tag is needed.

razor 
<head>
    ...
    <VelleStyles IncludeDatepicker="true" />
    <HeadOutlet />
</head>
<body>
    <Routes />
    <script src="@Assets["_framework/blazor.web.js"]"></script>
</body>

Legacy CLI & framework-agnostic bundles

Using the legacy Velle.Tool CLI (v{{ escape_html page.Site.Version }}) or CDN bundles

Before pivoting to Velle.Blazor, this repository distributed a framework-agnostic CLI tool (Velle.Tool on NuGet.org) and standalone dist/ bundles. Existing CLI users can still install v{{ escape_html page.Site.Version }}: 

dotnet new tool-manifest  # if needed
dotnet tool install Velle.Tool --version {{ escape_html page.Site.Version }}
dotnet tool run velle init
dotnet tool run velle add button dialog

Or load the static bundles via jsDelivr:

<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/codedbyshoe/velle-css@v{{ escape_html page.Site.Version }}/dist/velle.css">
<script type="module" src="https://cdn.jsdelivr.net/gh/codedbyshoe/velle-css@v{{ escape_html page.Site.Version }}/dist/velle.js"></script>
